# Канонические карты

Положи сюда полноразмерные скриншоты тактических карт + JSON-калибровку.

- `<map>.png` — само изображение карты, желательно высокого разрешения,
  без HUD и оверлеев.
- `<map>.json` — мета:
  - `canonical_size: [W, H]` — размер изображения.
  - `world_bounds` — границы мировых координат (берутся из `/admin/zones`).
  - `calibration_points` — 4+ соответствий `canonical_px ↔ world`.

Эта же калибровка переиспользуется в страничке `/admin/tracking-lab`.
